# Barahir EN translation - full disassembly

This project contains command line tools and scripts that help to disassemble and reassemble Barahir game with English texts.

Windows machine with several tools is expected...

PATH must contain:
- mads - http://mads.atari8.info
- alitrra64 - https://virtualdub.org/altirra.html
- dir2atr - https://www.horus.com/~hias/atari/#tools-win32
- python - https://www.python.org

Rest of the tools are local (part of the repository).

## To compile the game
run:
```build```

## To start the compiled game
run:
```run```

## Stuff you most likely not need
To decompile the original Polish version run:
```decompile```

To decompile the baratrans output version (partial translation) run:
```"decompile baratrans version.cmd"```
